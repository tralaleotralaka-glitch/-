# Нить — личный мессенджер

Небольшой полнофункциональный мессенджер на русском языке: регистрация по имени пользователя и паролю, поиск собеседников, личные диалоги и сообщения, которые сохраняются на сервере и доставляются в реальном времени через Server-Sent Events.

## Запуск веб-версии

Нужен Node.js 20 или новее. Зависимости устанавливать не нужно.

```bash
npm start
```

Откройте `http://localhost:3000`. Для разработки с автоматическим перезапуском сервера:

```bash
npm run dev
```

Можно задать порт через переменную окружения `PORT`.

## Как начать переписку

1. Создайте аккаунт: имя пользователя — от 3 до 20 символов (латиница, цифры и `_`), пароль — от 8 символов.
2. Чтобы проверить переписку между двумя людьми, откройте приложение в другом браузере или приватном окне и зарегистрируйте там второй аккаунт.
3. В первом аккаунте нажмите **Новый диалог**, найдите второго пользователя по имени и отправьте сообщение. Ответ появится в открытом диалоге в реальном времени.

Аккаунты, диалоги и сообщения хранятся в `data/store.json`. Этот локальный файл исключён из Git. Пароли хранятся в виде salted scrypt-хэшей; сессия — в HttpOnly cookie. Сообщения хранятся на сервере в открытом виде и не имеют сквозного шифрования.

## Android APK через GitHub Actions

В каталоге `android/` находится Android-приложение-оболочка. Оно открывает развёрнутую веб-версию мессенджера в защищённом WebView. Для переписки между устройствами сначала нужен работающий сервер мессенджера с публичным HTTPS-адресом: сам APK не заменяет сервер.

Рабочий процесс **Build Android APK** собирает устанавливаемый debug APK при push изменений Android-проекта или вручную:

1. Откройте вкладку **Actions** в GitHub и выберите **Build Android APK**.
2. Нажмите **Run workflow**. Можно указать адрес сайта в поле `web_app_url`.
3. После успешной сборки скачайте артефакт `nit-messenger-apk` внизу страницы запуска. В рабочей ветке APK также публикуется отдельным файлом в GitHub Release: `https://github.com/tralaleotralaka-glitch/-/releases/download/android-apk-latest/nit-messenger.apk`.

Если адрес не передан, приложение попросит ввести HTTPS-адрес сервера при первом запуске. Для сборки с адресом по умолчанию задайте GitHub Actions variable `WEB_APP_URL`. APK подписан debug-ключом для тестовой установки, не production-ключом Google Play.

## Как собрать APK вручную

Нужны JDK 17, Android SDK (API 35) и Gradle 8.9.

```bash
gradle -p android assembleDebug
```

Файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Для предварительной настройки сервера передайте `-PwebAppUrl=https://ваш-домен`.
